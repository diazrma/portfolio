Código que mantém a loja de pé. Ideias que vão além do backend.

Também gosto de construir ferramentas para outros devs: um módulo Magento que aponta más práticas no código, extensões de VS Code para o fluxo Magento e extensões de navegador. E, fora do trabalho, experimento com IA e criatividade, como o dorama Miados do Destino.
