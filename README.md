# Rodrigo Cardoso · Portfólio

Portfólio pessoal com uma aranha 3D interativa em que cada pata é uma skill.
Feito com HTML, CSS e JavaScript puro, sem bibliotecas nem build.

**Online:** https://diazrma.github.io

## Rodando localmente

Abra o `index.html` no navegador, ou sirva a pasta:

```bash
python3 -m http.server 8000
```

## Personalizando

- Skills (nome, nível, cor e texto): array `skills` no topo do `script.js`
- Velocidade e área do passeio da aranha: `WALK_SPEED` e `WANDER_RADIUS` no `script.js`
- Foto de perfil: `assets/profile.webp`
